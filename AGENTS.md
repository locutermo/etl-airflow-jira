# Reglas del Proyecto (Workspace Rules)

## Estilo y Diseño de Interfaz (UI/UX) y Código
- **Prohibición estricta de emojis e iconos tipo IA:**
  - No utilizar emojis decorativos en títulos, botones, tarjetas, métricas, tablas, diálogos, logs ni alertas (por ejemplo: ⚡, 💾, 🔄, 🗑️, ➕, 🟢, ⚪, 🚀, 🤖, 💡, ✨, 🎯, 🔥, 🛠️, 📈, 🚨, etc.).
  - El diseño visual de la interfaz de usuario (Streamlit, HTML/CSS) y los mensajes del sistema deben mantener una apariencia estrictamente sobria, corporativa, profesional y de estándar bancario/empresarial.
  - Para representar estados, utilizar etiquetas de texto sobrio (ejemplo: `[ACTIVO]`, `[EN ESPERA]`, `[EXTRAYENDO]`, `[INACTIVO]`, `[ERROR]`, `[OK]`) o indicadores CSS minimalistas sin recurrir a emojis.
  - Los nombres de botones y acciones deben ser directos y formales (ejemplo: `Actualizar Hilos`, `Auto-Mapear Pantallas`, `Regularizar Histórico`, `Limpiar Mapeo`, `Incorporar Campos`).
